# SpringAI-GIS: System Architecture & Design Specification

## 1. Executive Summary
**SpringAI-GIS** is an AI-powered Geospatial Information System (GIS) and Hydrogeological Decision Support System built for government agencies, water resource boards, hydrogeologists, GIS analysts, and field officers.

The primary objective is the scientific delineation of **Probable Spring Recharge Zones (Springsheds)**, estimation of recharge suitability, transparent risk analysis, indicative intervention recommendations, field validation tracking, and model feedback learning.

## 2. Scientific Core: Recharge Potential vs. Confirmed Recharge Zone
In accordance with hydrogeological science, all AI and algorithmic delineations are classified as **"Probable Recharge Zone / Recharge Suitability"**. A recharge zone can only be elevated to **"Confirmed Recharge Zone"** upon multi-season field validation, isotopic tracer analysis, structural geologic ground-truthing, and hydrogeologist approval.

## 4. Role-Based Access Matrix
| Role | View Springs & Maps | Delineate Springshed | Review & Validate | Manage Users & Models | Field Capture |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Administrator** | Yes | Yes | Yes | Yes | Yes |
| **Hydrogeologist** | Yes | Yes | Yes | No | Yes |
| **GIS Analyst** | Yes | Yes | No | No | No |
| **Field Officer** | Yes (Assigned) | View Only | Submit Only | No | Yes |
| **Researcher** | Yes (Approved) | View/Compare | No | No | No |
| **Viewer** | Read-Only | Read-Only | No | No | No |

## 5. Security & Provenance
- All predictions store metadata: Model ID, Version, Dataset Hash, Feature Array, Timestamp, Generated By.
- No secrets committed in repository.
- Sensitive state guarded by JWT token authentication and role checking.
